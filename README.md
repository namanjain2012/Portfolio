## Featured Projects

### 1. Hinglish Sarcasm Detection System

A natural language processing project for detecting sarcasm in Hinglish social media comments, developed as an extension of a cyberbullying detection project.

- Used NLTK and WordNet (OMW) for text preprocessing and multilingual lexical enrichment.
- Applied pretrained NLP techniques, including T5 paraphrasing and SBERT embeddings, to improve semantic understanding.
- Achieved **95.35% test accuracy** during model evaluation and experimentation.

**Technologies:** Python, NLP, NLTK, WordNet, T5, SBERT

### 2. Intelligent Product Search Engine

A typo-tolerant internal search engine built for the IVR team to find Apple products and related items.

- Used FuzzyWuzzy-based fuzzy matching to improve query accuracy by approximately **85%**.
- Integrated store stock data from across India using Pandas and NumPy.
- Built a responsive web interface with HTML, CSS and Flask.
- Reduced manual lookup time by approximately **70%**.

**Technologies:** Python, FuzzyWuzzy, Flask, HTML, CSS, Pandas, NumPy

## Installation

To run the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/namanjain2012/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in your browser. You can double-click the file, or use a local development server if preferred.

Keep the existing `assets/` directory alongside `index.html`; it contains the stylesheet, JavaScript, images, and favicon used by the site.
